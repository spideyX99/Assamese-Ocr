Features of Assamese OCR Tool

✅ Automatic OCR from PDF
✅ Detects both Assamese and English languages
✅ Advanced Image Processing (Grayscale + Contrast Enhancement)
✅ Progress Bar to show OCR completion
✅ Estimated Time Left for processing
✅ Extracted Text can be saved and downloaded


How does the OCR work?

This OCR tool uses PDF.js and Tesseract.js to recognize Assamese and English text from PDFs.
